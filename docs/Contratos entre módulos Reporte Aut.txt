Contratos entre módulos: Reporte Automático de Ventas con pandas

1. main.py

Recibe:

* No recibe datos directamente al iniciar, porque es el punto de entrada del programa.
* Durante la ejecución puede solicitar o recibir la ruta del archivo CSV.

Devuelve:

* No necesita devolver datos principales.
* Su responsabilidad es coordinar el flujo completo del programa.

Responsabilidad central:
main.py funciona como el coordinador general del sistema. No valida datos, no analiza métricas, no genera reportes manualmente y no guarda archivos directamente. Solo conecta los módulos en el orden correcto.

2. validator.py - validación de archivo

Recibe:

* La ruta original del archivo CSV.

Devuelve:

* Una ruta validada, preferentemente como objeto Path.

Si hay error:

* Lanza o devuelve un error personalizado relacionado con la ruta, extensión, archivo vacío, archivo inexistente o archivo ilegible.

Responsabilidad central:
Validar que el archivo pueda ser usado antes de intentar leerlo con pandas.

3. csv_reader.py

Recibe:

* Una ruta validada del archivo CSV.

Devuelve:

* Un DataFrame crudo.

Nombre sugerido:
df_raw

Responsabilidad central:
Leer el archivo CSV usando pandas y convertirlo en una tabla de datos. Este DataFrame todavía no se considera limpio ni válido.

4. validator.py - validación del DataFrame

Recibe:

* Un DataFrame crudo.

Nombre esperado:
df_raw

Devuelve:

* Un resultado de validación.

Nombre sugerido:
validation_result

El resultado de validación debe contener:

* df_valid_rows
* df_invalid_rows
* errors
* warnings
* total_rows
* total_valid_rows
* total_invalid_rows

Responsabilidad central:
Revisar el contenido del DataFrame, validar columnas obligatorias, detectar filas válidas, detectar filas inválidas, registrar errores y registrar advertencias.

5. analyzer.py

Recibe:

* DataFrame de filas válidas.
* Totales generales necesarios para el reporte.

Nombres esperados:

* df_valid_rows
* total_rows
* total_valid_rows
* total_invalid_rows

Devuelve:

* Un resultado de análisis.

Nombre sugerido:
analysis_result

El resultado de análisis debe contener:

* total_rows
* total_valid_rows
* total_invalid_rows
* total_income
* total_units_sold
* best_selling_product
* highest_income_product
* highest_income_category
* product_summary
* category_summary

Responsabilidad central:
Calcular métricas usando únicamente filas válidas. No debe validar datos ni generar texto final del reporte.

6. reporter.py

Recibe:

* Resultado de análisis.
* Errores detectados.
* Advertencias detectadas.
* Nombre del archivo analizado.
* Fecha de generación.

Nombres esperados:

* analysis_result
* errors
* warnings
* source_filename
* generation_date

Devuelve:

* Texto completo del reporte.

Nombre sugerido:
report_text

Responsabilidad central:
Construir el reporte automático de ventas en formato legible para el usuario. No debe guardar archivos ni recalcular métricas.

7. file_manager.py

Recibe:

* Texto del reporte.
* Nombre deseado para el archivo de salida.
* Carpeta de destino.

Nombres esperados:

* report_text
* output_filename
* output_folder

Devuelve:

* Ruta final donde se guardó el reporte.

Nombre sugerido:
report_path

Responsabilidad central:
Crear la carpeta de reportes si no existe, guardar el reporte como archivo .txt y devolver la ruta final del archivo generado.
